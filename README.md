
Airplane Track Handling VR Game
An interactive VR game built with Unity and C# for Meta Quest 3. The game features two airplane landing scenarios where players use natural hand gestures to guide and instruct incoming aircraft.
Developed as part of a VR interaction study (June 2024 – August 2024).

Features:

Hand gesture-based airplane guidance

Two different landing scenarios

Designed for Meta Quest 3 (using hand tracking, no controllers)

Immersive VR experience for training and entertainment purposes
